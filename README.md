# Морской Медицинский Центр - новый сайт (демо)

Статический сайт, собирается из `content/*.json` скриптом `build.py` (Python 3, без зависимостей).

```
python3 build.py              # -> site/
cd site && python3 -m http.server 8790
```

- `content/` - услуги, врачи, прайс, данные клиники
- `src/` - стили, скрипт, изображения, логотип
- Адреса страниц совпадают со старым seamc.ru
- Демо: noindex, форма заявки ничего не отправляет
